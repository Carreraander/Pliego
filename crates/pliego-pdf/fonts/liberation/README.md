# Liberation Fonts 2.1.5 (SIL Open Font License 1.1)

Los 12 archivos `.ttf` de esta carpeta son los de Liberation Fonts 2.1.5 **sin modificar**
(<https://github.com/liberationfonts/liberation-fonts>). Son compatibles en métrica con Arial/Helvetica (Sans),
Times New Roman/Times (Serif) y Courier New/Courier (Mono).

Los usa `pliego_pdf::native::Font` para medir y dibujar los contornos de las 14 fuentes estándar de PDF
(Helvetica, Times, Courier) sin depender de MuPDF. El documento PDF que se genera hace referencia a las fuentes
estándar por nombre, sin incrustarlas.

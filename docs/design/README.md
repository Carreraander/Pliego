# Bocetos de diseño

- `boceto-visor.html`: boceto estático del visor (tema claro y oscuro). Ábrelo en un navegador.

Dirección visual (pendiente de aprobación de Ander): papel cálido y verde tinta (`--accent`), pestañas arriba,
barra fina de herramientas, raíl de paneles a la izquierda, zoom flotante. Sin rojo corporativo ni disposición
copiada de otros editores de PDF. Los tokens definitivos irán a `app/src/styles/tokens.css`.

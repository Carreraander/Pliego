# W28 · Conectar Firmas a la app (ola 4)

- **Plan:** [`docs/workstreams/ola4-conectar-herramientas.md`](../../workstreams/ola4-conectar-herramientas.md), fila W28.
- **Estado a 2026-11-04:** primer PR abierto con las tres herramientas conectadas. Sin probar en acr12 ni en pantalla.

## Qué hay

- **Servicio** (`app/service/src/sign.rs`, sin Tauri, con pruebas): `list_certificates`, `sign_pdf`, `validate`, `flow_prepare`, `flow_next`, `flow_sign`, `flow_audit`. Clave = `KeySource::Store { thumbprint }` (almacén de Windows, vale para el DNIe) o `KeySource::Pfx { path, password }`. Siempre se escribe una copia; nunca se firma sobre el original.
- **Comandos Tauri** (`commands/sign.rs`): `sign_list_certificates`, `sign_pdf` (trabajo → `<nombre> (firmado).pdf`), `sign_validate`, `signflow_prepare` (trabajo → `(para firmar)`), `signflow_next`, `signflow_sign` (trabajo), `signflow_audit`; y `pick_key_file` en `dialog.rs`.
- **Interfaz** (`app/src/tools/sign/`):
  - `sign.digital`: asistente con certificado de Windows o PFX, nivel B-B/B-T/B-LT/B-LTA (servidor de sellado obligatorio desde B-T), firma visible en una esquina, certificación DocMDP, motivo/lugar/contacto.
  - `sign.validate`: panel «Firmas» en el raíl con el estado de cada firma (válida, emisor no reconocido, modificada, inválida; cadena, sello, DSS).
  - `sign.workflow`: preparar el paquete con firmantes en orden, firmar mi turno y ver el registro.
  - `facts.ts` (`installSignatures`): fija `setDocFacts({ signatures })` según el documento activo y muestra el aviso «Firmado por…» (prioridad `signed`).

## Notas y huecos

- **`document` en `DocFacts`:** lo fija gestión en `installNavigation()` (efecto sobre `activeDoc()`); `installSignatures` solo fija `signatures`.
- **Confianza de la cadena:** `validate` no lleva raíces propias, así que un certificado válido pero de una CA que Pliego no conoce sale como «emisor no reconocido» (aviso ámbar). Falta cargar las raíces de confianza de Windows / la lista de confianza de la UE (decisión de producto).
- **Firma visible:** posición por esquinas con tamaño fijo 200×60 pt; colocarla arrastrando sobre el visor queda para una iteración con W26 (capa interactiva).
- **Documentos con contraseña** no se firman desde el asistente todavía.
- **Pendiente en acr12 (con turno):** firmar con un certificado real del almacén y con el DNIe (cuando haya lector), B-T con TSA real, y revisión visual de los tres paneles (a `revision-manual-ander.md`).
- Las pruebas de servicio usan PFX autofirmados generados al vuelo; el almacén de Windows solo se ejercita en acr12.

Download Pliego for Windows

Pliego is in pre-release. The first public beta will be published on this page. Until then you can follow the project or build it from the source code.
Follow the project on GitHub

Requirements

  • Windows 10 or Windows 11, 64-bit.
  • WebView2, which comes with Windows 11 and with an up-to-date Windows 10. If it is missing, the installer downloads it from Microsoft.
  • No administrator rights needed: Pliego installs for your user. To install it for every user on the PC, choose that option in the installer.

Installing

  • Run Pliego Setup and click Install. You can make Pliego your default PDF app from the installer itself.
  • To install it silently on many PCs: Pliego-Setup.exe --silent.
  • To uninstall it, use Windows Settings > Apps, like any other program.

Checking the download

Each release publishes its SHA-256 checksum next to the installer. In PowerShell, run Get-FileHash .\Pliego-Setup.exe and compare the result.

Updates

Pliego checks for updates signed with Ed25519 and tells you before installing them. If a new version fails to start, it goes back to the previous one on its own. You can turn updates off in Settings > Updates.

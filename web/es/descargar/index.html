Descargar Pliego para Windows

Pliego está en prelanzamiento. La primera beta pública se publicará en esta página. Mientras tanto puedes seguir el proyecto o compilarlo desde el código fuente.
Seguir el proyecto en GitHub

Requisitos

  • Windows 10 o Windows 11 de 64 bits.
  • WebView2, que ya viene con Windows 11 y con Windows 10 actualizado. Si falta, el instalador lo descarga de Microsoft.
  • No hace falta ser administrador: Pliego se instala para tu usuario. Para instalarlo para todos los usuarios del equipo, elige esa opción en el instalador.

Instalación

  • Ejecuta Pliego Setup y pulsa Instalar. Puedes hacer que Pliego abra los PDF por defecto desde el propio instalador.
  • Para instalarlo sin preguntas en muchos equipos: Pliego-Setup.exe --silent.
  • Para desinstalarlo, usa Configuración de Windows > Aplicaciones, como cualquier otro programa.

Comprobar la descarga

Cada versión publica su suma SHA-256 junto al instalador. En PowerShell: Get-FileHash .\Pliego-Setup.exe y compara el resultado.

Actualizaciones

Pliego busca actualizaciones firmadas con Ed25519 y te avisa antes de instalarlas. Si algo falla al arrancar una versión nueva, vuelve solo a la anterior. Puedes desactivarlas en Ajustes > Actualizaciones.

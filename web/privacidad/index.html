Privacidad

Esta página explica qué datos tratan el sitio pdfpliego.com y el programa Pliego. La respuesta corta: ninguno que te identifique.

El sitio web

  • No usa cookies, ni analítica, ni píxeles de seguimiento, ni fuentes o scripts de terceros.
  • El servidor guarda un registro técnico de las peticiones (dirección IP, fecha, página pedida y navegador) durante 7 días para detectar abusos y errores. Después se borra.

El programa

  • Pliego no tiene cuenta de usuario ni telemetría. Tus documentos se procesan en tu equipo y no se envían a ningún servidor.
  • Para buscar actualizaciones, Pliego pide un archivo al servidor de actualizaciones. La petición solo indica la versión instalada y que es Windows. Puedes desactivar las actualizaciones en Ajustes y entonces Pliego no se conecta a nada.
  • Algunas funciones que tú eliges usar sí se conectan: por ejemplo, el sellado de tiempo de una firma electrónica consulta al servidor de sellado y a las listas de revocación del certificado.

Responsable

Para cualquier pregunta sobre privacidad, abre una consulta en GitHub.

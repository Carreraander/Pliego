Privacy

This page explains what data the pdfpliego.com website and the Pliego app handle. The short answer: none that identifies you.

The website

  • It uses no cookies, no analytics, no tracking pixels and no third-party fonts or scripts.
  • The server keeps a technical log of requests (IP address, date, page requested and browser) for 7 days to detect abuse and errors. After that it is deleted.

The app

  • Pliego has no user account and no telemetry. Your documents are processed on your PC and are never sent to a server.
  • To check for updates, Pliego requests a file from the update server. The request only includes the installed version and the fact that it runs on Windows. If you turn updates off in Settings, Pliego does not connect to anything.
  • Some features you choose to use do connect: for example, timestamping an electronic signature contacts the timestamp server and the certificate’s revocation lists.

Who is responsible

For any privacy question, open an issue on GitHub.
